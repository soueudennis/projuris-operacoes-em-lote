# Projuris Empresas — Operações em Lote com IA

Protótipo de interface para execução de ações em lote em processos jurídicos,
com sugestões assistidas por IA.

## Como executar

Abra `Operacoes em Lote com IA.html` diretamente no navegador (sem build ou servidor necessário).

## Funcionalidades

- Seleção múltipla de processos na lista
- Operações em lote: trocar advogado, encerrar, alterar status, etiquetar, delegar tarefas
- Sugestões de IA com score de confiança
- Wizard modal de 4 fases: configurar → revisar → aplicar → concluído
- Busca com filtro por termo exato
- Janela de reversão de 24h com log de auditoria
